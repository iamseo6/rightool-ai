# Find an AI tool with RighTool.ai

Use the RighTool.ai public directory to find an AI tool for a job.

1. Browse the directory at https://rightool.ai/directory or a category page such as https://rightool.ai/category/chatbots.
2. For the full machine-readable list of all 45 tools, read https://rightool.ai/llms.txt.
3. Open a tool page (for example https://rightool.ai/tool/chatgpt) for pricing, pros, cons, and the official homepage link.
4. Rankings are not paid; see how tools are ranked at https://rightool.ai/how-we-rank.

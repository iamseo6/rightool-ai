# auth.md — RighTool.ai

## Audience

This document is for AI agents interacting with RighTool.ai, a public directory of AI tools.

## Authentication

No authentication is required. RighTool.ai has no protected APIs, no login, and no OAuth authorization server.

## Registration

There is no registration or provisioning endpoint. Agents do not need to register, and no credentials are issued.

## Credentials

No credentials are used. All public resources below are openly accessible without keys or tokens.

## Public resources

- Tool directory: https://rightool.ai/directory
- Full tool list (Markdown): https://rightool.ai/llms.txt
- Every page: https://rightool.ai/sitemap.xml
- Capability manifest: https://rightool.ai/.well-known/ai-catalog.json
- Agent skills index: https://rightool.ai/.well-known/agent-skills/index.json
- API catalog: https://rightool.ai/.well-known/api-catalog
- API documentation: https://rightool.ai/.well-known/api-doc.md

## Contact

For listing or sponsorship questions, use the Submit page (https://rightool.ai/submit) or the Contact page (https://rightool.ai/contact). Those forms prepare a message for the site owner; they do not send from the page.
